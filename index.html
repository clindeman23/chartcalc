📖 How grades are calculated
With Exam:Q1+Q2 → Chart A quality points + Midterm → Chart B → Semester grade. Q3+Q4 + Final → same. Sem1+Sem2 → Chart C → Year. No Exam:Q1+Q2 → Quarter Chart → Semester grade. Sem1+Sem2 → Chart C → Year. (Midterm/Final fields are disabled.) "Has Exam" ✓:Check this box if the class has a Midterm or Final exam score. Uncheck for quarter-only classes (electives, gym, etc.). Flag ⚑:Check when the calculated grade doesn't match what's on the transcript — flags the row in red for the printed copy.
